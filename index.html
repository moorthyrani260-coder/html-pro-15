WinZip Self Extractor Instructions

  • Preparing the files
    1. Prepare a text document containing the message that users will see when the executable opens.
    2. Write a batch file to copy the required exercises and save it in the main folder.
    3. Compress the required files into a ZIP archive.
  • Building the executable
    1. Open WinZip Self Extractor and proceed through the first three setup screens.
    2. Specify the ZIP archive name in the fourth dialog box.
    3. Select the Next button to test the executable file.
